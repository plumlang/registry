# LICENSES

The canonical licence texts and exceptions of the **Elixpo licensing
standard**, as used in this repository. The root [`LICENSE`](../LICENSE) is
the pointer; per-product reservations are in the root [`NOTICE`](../NOTICE).

| Path | SPDX ID | Used for |
|---|---|---|
| `preferred/MIT` | `MIT` | All code: `tools/`, `.github/` workflows and actions. |
| `preferred/CC-BY-4.0` | `CC-BY-4.0` | Written content: `README.md`, `CONTRIBUTING.md`, the issue forms' text. |
| `preferred/CC0-1.0` | `CC0-1.0` | The index metadata: `index/` and `search.json`. |
| `exceptions/Plumlang-trademarks` | `Plumlang-trademarks` | Reserves the Plumlang name and marks (with MIT and CC-BY-4.0). |
| `exceptions/Oreo-trademarks` | `Oreo-trademarks` | Reserves the Elixpo and Oreo names and identity; incorporated by `Plumlang-trademarks`. |
| `notices/notice-board` | | Third-party components and their licences. |

The bundles under `packages/` are the published packages, each under its
own licence (its `plum.toml` and `LICENSE`).

By submitting a pull request you agree your contribution is licensed inbound
under this standard (MIT for code, CC-BY-4.0 for content, CC0-1.0 for index
metadata) and that you have the right to submit it. The
[Developer Certificate of Origin](https://developercertificate.org) applies
to every commit. We do not require a CLA.
